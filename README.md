# 拾想 · IdeaPickup

让随手录下的想法进入自己的收件箱。设备可离线把录音保存在 SD 卡上并回放；配置自管服务后，自动用千问转写并把文字写入思源云端收集箱。没有 SD 卡时提供联网录音托底，不提供音频回放或云端音频库。

本源码为 R12 验收修订；历史首发候选为 `0.2.0rc1`。两板本轮必做真机检查已完成，完整低电矩阵由所有者跳过、斑梨一项历史看门狗告警明确延期，不能据此称所有风险消除。后端已有隔离容器及真实 HTTPS、千问→思源结果。可获取的版本和附件以发布入口及对应Release为准。固件版本由构建时的 Git 或归档源摘要生成，以精确产物和输入校验值识别；完整范围见[支持状态](docs/SUPPORT.md)，获取说明见[发布入口](docs/PUBLIC_RELEASE.md)。

## 开始使用

1. **部署后端。** 在 Linux rootful Docker / Compose V2 上，从[候选发布入口](docs/PUBLIC_RELEASE.md#获取-020rc1-候选)取得固定镜像或按[部署说明](docs/DEPLOYMENT.md)自行构建，本地电脑填内网 IP 即可（默认 HTTP 8765，无需域名/证书）；服务器填域名，采用可信 HTTPS。两者均可带端口和子路径。本地 IP 支持是当前未发布的 R12 修正，须构建当前源码，已发布 rc1 镜像不包含此功能。
2. **配置服务。** 从部署机取得一次性初始化码，在 `<服务地址>/admin/` 设置管理员密码；填写千问 API Key 和思源云端 Token，一次保存生效。生成设备的一次性配对码。
3. **安装设备固件。** 选择 16 MB 喵伴 `vocat16` 或斑梨 `spotpear`，按[安装说明](docs/DEVICE_INSTALL.md)构建、打包并通过可用的下载入口安装。当前没有稳定固件附件，不混用板型。
4. **配网和配对。** 设备长按猫脸三秒，连接屏幕所示热点，打开 `http://192.168.4.1`；在浏览器中保存 2.4 GHz Wi-Fi，等待页面显示已连接且保存完成；选择「转写服务」，填内网 IP 或 HTTPS 服务域名和配对码，等待页面显示已配对后再关闭热点。页面会更新连接和配对结果，切出后可回到原地址查看。仅本地使用可跳过服务配置，有卡录放保持离线可用。
5. **录音与同步。** 用触摸或本地语音开始／停止录音；有卡记录可从列表回放、暂停／继续／停止。详情显示实际同步状态，失败时只提供可执行的刷新或重试；无卡模式有固定标记、不能回放，需要网络和已配置服务。

设备不填写千问 Key、思源 Token 或管理员密码。同一后端可配对多台设备，设备协议不限制型号；新硬件仍需单独适配。更换 Wi-Fi 可单独保存 Wi-Fi，不必重新输入服务配对码。

成功或拒绝后中继清理暂存音频；失败／中断的闲置暂存最长 24 小时，状态查询不续期。投递完成清理暂存正文。投递不确定时处理该条结果，不盲目重发。

## 开发和更新

固件与主机环境只安装在工程目录。需要 uv **0.12.5**、Git、C/C++ 编译器、clang、Node、OpenSSL 和主机 libopus；Python、SDK、组件和容器依赖由锁文件决定。

```sh
./scripts/bootstrap.sh
./scripts/setup_relay.sh
./scripts/test_all.sh
./scripts/build_vocat16.sh
./scripts/build_spotpear.sh
```

完整命令见[测试说明](docs/TESTING.md)，维护、兼容更新和数据保持见[开发说明](CONTRIBUTING.md)。普通后端更新保留原卷，普通固件更新只写应用；无需清空本轮产生的配置、授权或录音。首次使用面向全新安装，不导入旧项目历史；未来不兼容格式需单独说明处理方法。

不要公开 API Key、设备令牌、原始日志、录音或数据库；本地测试材料放 `private/`。安全问题见[安全政策](SECURITY.md)，来源与资源许可见[第三方声明](THIRD_PARTY_NOTICES.md)。项目原创代码采用 [Apache-2.0](LICENSE)，第三方代码、动画、字体、模型和提示音各自保留原许可。

当前发布范围和后续主线见[发布说明](docs/PUBLIC_RELEASE.md)。源码和 Docker 的候选发布不表示固件已经稳定，真机结果以支持表为准。
