# 设备配置、任务与保留数据

当前直连实现以[配置与接口契约](contracts/firmware-direct-cloud-v1.json)为准。设备直连已经过两板验收，当前交付范围见[本地候选说明](DEVICE_DIRECT_CLOUD_DELIVERY.md)。

云配置写入默认NVS的独立 `memo_cloud1/config`：604字节、版本／CRC、两项凭据代次、模式。密钥经设备的 WPA2 配网热点提交，或通过 USB 维护工具隐藏输入；网页只返回保存状态。热点密码独立保存在 `memo_ap/password`。不变不写；写入、commit后关闭handle并精确回读，失败重新读取实际值。缺失为本地未配置，坏／未来格式拒绝覆盖，不借旧token补齐。

`memo_ids1` 沿用统一设备高水位，分配前持久保留；SD本地回退避让WAV及新旧sidecar编号。新有卡任务只写 `direct_r1_*.job.0/.1` 和每录音唯一有界临时文本，详情不扫描音频／计算SHA或联网。保存成功的新联网录音创建一次意图；仅本地历史不自动补交。成功／取消清理文本，失败按可靠阶段保留；不确定不自动重发。

无卡新状态在原 `memo_meta` 分区的 `direct1`：单条128字节、活动键12字节，没有音频／全文写入NVS。最多1024×16字节索引和四详情槽，分区空间不足拒绝新任务、不删除未决历史。PCM及最终文本仅在本次会话有界保留；成功／失败／取消释放。启动只把新未结束状态收尾为中断、取消或投递不确定，不恢复流或轮询历史。

原 `memo_cfg1`、`records1`、`sync_r1`、原录音和备份继续保留。旧配置不日常加载，旧记录只读；旧未决来源显示待核对，不向旧服务请求，也不创建新的直连提交。[旧配置契约](contracts/firmware-config-v1.json)与[旧任务契约](contracts/firmware-tasks-v1.json)仅解释历史中继格式，已被当前契约替代，不是新应用的运行入口。

不更改分区、不自动擦除／格式化，不回退编号高水位。回退必须保全新数据，并使用第一步决定中匹配应用／数据副本及最大已分配编号的流程。NVS未加密的物理提取风险仍存在；本轮不烧安全熔丝，也不声称USB具备抗本机恶意软件能力。

有卡的转写检查点与临时正文随卡保留，已确认文本可从检查点继续。成功和确定取消后清理临时正文，失败时仅保留同一任务的一份有界临时正文。思源收件结果不确定时停止自动重发。无卡历史只保留有限状态，音频与正文缓存随任务结束释放。更换凭据用[网页凭据配置](DEVICE_INSTALL.md#direct-setup)，回退前备份 SD 与原 Flash 材料。
