## 配置入口

设备空闲并主动开启配置热点时，在可信电脑USB终端运行：

```sh
.venv/bin/python scripts/configure_cloud.py
# 多个设备时明确指定其中一个串口：
.venv/bin/python scripts/configure_cloud.py --port /dev/目标串口
```

助手只在唯一Espressif设备时自动选中；不确定则列出候选并要求指定，保持应用CDC所需DTR已置位、RTS未置位，不执行复位序列或bootloader命令；真实重开USB仍在第六步验证。Workspace普通输入，千问Key／思源Token隐藏输入；非交互终端或隐藏输入降级时拒绝。秘密不作为参数，不落文件、不输出原始串口流／异常内容。Python不可变字符串不能保证物理内存清零；它不是USB加密或抵抗本机恶意软件的方案。

设备复用console但进入独立接收：最大1024字节，15秒无输入清空退出，溢出整次拒绝，不执行截断前缀。斑梨在输入窗口临时用官方VFS O_NONBLOCK避免阻塞超时，退出恢复原标志；喵伴原CDC读取本就非阻塞。两板RX均为1152字节，容纳完整1024字节行与换行／USB包余量，不改USB控制器或描述符。只返回READY／结果数字；空字符串保留原值，明确clear才删除。可用 `--clear-qwen`／`--clear-siyuan`，清除会转为仅本地。临时接收和配置可变缓冲结束时清零。JSON复用直连模块隔离的SDK解析器，使用一次性16KiB堆arena；成功、部分解析失败、未知字段和分配失败均整块清零释放，不改变共享cJSON的全局hooks。

保存只改一个604字节NVS blob。工作区使用一次性有界内部堆临时区，避免在原4096字节console栈堆叠多份配置；退出清零释放。空闲准入、COMMIT／AUDIO／MEDIA门闩、同HTTP所有者排除复用原能力；不添加任务／通用设置框架。197／162空条目只作准入，仍须实际set／commit／新handle回读成功；失败重载真实当前值，不能冒称成功。代次只在相应账号内容变化时增加，溢出拒绝；同值保存不写、不触发业务或中断无卡任务。BUSY拒绝不刷新配置；确认后的RAM及无卡准入刷新始终在COMMIT内。若提交后读取失败，缓存标记未确认；故障解除后的明确网页刷新在同一互斥下重新确认并恢复缓存，不写NVS或调用供应商。

## 页面与设备状态

保留用户选定A布局＋B配色及描边、对等模式、Wi-Fi信号／锁图标和对齐按钮。长期凭据从原开放HTTP字段迁到USB是明确的技术渠道限制；网页只显示两项是否已存、配置助手指引、模式和明确清除，不用已退役的服务器地址／配对码。没有美学方案重做。

保存、Wi-Fi连接、凭据未验证和实际任务结果分开显示。“凭据已保存”不表示账号验证；最近处理状态只来自真正SD／无卡执行器，区分转写、投递、已送达、失败和不确定。保存不做付费测试／试投递；更换凭据清除旧账号的最近结果提示，历史本地状态仍保留。

HTTP模式／清除提交带配置代次，拒绝旧页覆盖和重复／未知字段；原Host／Origin／CSRF／Content-Type／长度／深度和退出边界保留。Wi-Fi草稿、保存期间的新模式草稿、后台停止轮询／返回刷新、可见处理2秒／稳定10秒、手动Safari和明确退出保持；不恢复系统弹页或DNS通配。

设备首页／配网页不再说“配对中／已配对”。LVGL使用网络RAM快照显示本地／待配置／尚未验证，不在每帧读取NVS。详情仍以本地任务状态为准，全文到思源看。
