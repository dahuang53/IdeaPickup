# 直连固件清理补充

本次清理接续[直连改造计划](DEVICE_DIRECT_CLOUD_PLAN.md)，适用于支持密码热点和网页保存凭据的本地候选。公开旧中继版本及其后端仍按各自版本说明使用。

| 范围 | 处理结果 |
|---|---|
| 录音详情 | 只更新最终的提交／取消按钮文案；状态不变时不反复写入旧文案或切换隐藏标记。旧录音状态数值保留，移除没有实际数据来源的上传百分比。 |
| 存储入口 | 删除无生产调用的旧 begin/list 包装和无卡 recording 查询；测试覆盖迁到实际使用的精确编号、卡内回退编号及索引入口。 |
| 重复读取 | 首次提交复用已验证的 WAV 信息；扫描每条双槽状态只解码一次，仍支持单槽和损坏槽恢复。 |
| 历史兼容 | 旧目标、摘要和采样确认字段在解析器内验证，不再携带到当前运行结构。旧文件／NVS 格式不变，也不重写旧记录。 |
| 网络调度 | 移除恒为零的旧游标及失效的扫描分支；保留现行手动提交、取消、联网续处理和统一编号边界。 |
| 依赖 | 移除没有调用方的软件编解码组件 esp_audio_codec；保留硬件音频驱动 esp_codec_dev。显式锁定既有 dl_fft 0.7.0，避免无关依赖升级。 |
| 配网组件 | 删除未参与页面选择的语言参数；补丁说明更新为持久 WPA2 热点、物理换密及网页写入／替换／清除凭据。 |
| 测试入口 | 直连流程回归使用现有通用主机 Python 环境；旧中继测试保留其独立环境。 |

串口诊断不再输出无效的 NETWORK cursor、启动 baseline 或 RECORD_SYNC percent 字段。自动化应按字段名读取，不应假定这些历史占位值表示实际进度。录音编号、处理状态和任务排队信息继续提供。

历史状态解码器、TLS、网络超时所有者、音频硬件驱动、录放、USB、按需探卡、恢复材料及独立后端均有现行用途，继续保留。清理不计算音频 SHA、不自动提交旧录音，也不改变凭据和录音的磁盘格式。

验证使用[现有测试入口](TESTING.md)：存储／无卡合成回归、旧格式冲突与坏槽检查、真实 LVGL 重复刷新观察、配网页配置夹具及两板锁定构建。合成与静态检查不替代实听或电池续航测量，也不消除[已知限制](DEVICE_DIRECT_CLOUD_DELIVERY.md)。
