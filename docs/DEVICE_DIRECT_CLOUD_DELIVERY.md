# 设备直连预发布 2026.11.05-rc1

本版本包含 `vocat16`、`spotpear` 两套 16 MB 固件及匹配源码。[版本与下载](PUBLIC_RELEASE.md)提供附件、校验值和历史版本；安装与更新步骤见[设备安装说明](DEVICE_INSTALL.md)。本版直接连接千问 AI 平台与思源云端收集箱，无需中继。

源码包内的 `PUBLIC_SOURCE_MANIFEST.json` 列出公开源文件及其哈希。板包内的 `firmware/manifest.json` 记录板型、源码身份、锁定 SDK、编译输入和固件哈希；用 Release 中的 `SHA256SUMS` 核对每个已下载附件。源码、安装脚本和固件应来自同一版本。

## 本版验收与适用范围

| 范围 | 已核对的行为 |
|---|---|
| 构建和清理 | 两板锁定构建、主机及三种 UI 布局回归、打包和旧模块移除检查通过；清理经独立审计，见[清理补充](FIRMWARE_CLEANUP.md)。 |
| 喵伴最新验收候选 | 受保护安装、实际启动、原配置及历史保全通过；原 Wi-Fi 与两项供应商凭据仍可用，设备保持联网转写模式。 |
| 手机配置 | 喵伴实测密码热点重连、屏幕主动换密、Safari 写入凭据及切出返回；保存原值的前后配置一致。密码和长期凭据均未放入公开材料。 |
| 真实端到端 | 在喵伴上由本机合成语音经扬声器／物理麦克风录制 12.384 秒，设备自动完成真实千问转写与思源投递；正文中的测试编号、时间和地点符合预期，收集箱只新增一条。查看详情并软件重启后观察约 40 秒，仍为同一条云笔记、状态已送达且队列为空。 |
| 斑梨最新清理版 | 本轮完成构建和主机回归，没有重刷、触摸或实听复验；不将前序结果表述为本版全部真机重测。 |

上述真机证据绑定对应验收候选的生产输入；发布包以最终源码构建，精确身份由各自 manifest 和文件哈希区分，不仅凭版本字符串判断。

## 前序直连证据

前序直连候选已完成两板实际安装、录音及操作验收，喵伴有卡／无卡真实转写与思源收件，斑梨合成成功／拒绝／断线／取消各五轮，以及有卡断网后继续同一任务并完成一次投递。两板处理过 120 秒合成 PCM 和 64 KiB 分片事件，喵伴实际检查过四条配网连接及第五条 LRU 淘汰。历史音频与状态抽查、终态无额外请求和资源清理分别留有记录。

这些结果按未改变的生产逻辑和受影响范围复用。原资源对照采用同一设备、同一启动阶段的旧读数与直连 R2 实测，卡状态及配置有差异；不等同于电流或续航测量。协议与上限见[直连契约](contracts/firmware-direct-cloud-v1.json)和[测试说明](TESTING.md)。

## 保留的限制

- 无卡音频跨断网、断电或重启恢复另行研究；当前没有持久音频可供回放或设备重试。
- 两板完整真实低电策略／恢复矩阵未验证，没有续航保证。
- 斑梨长录音导出的间歇看门狗告警后续八轮未复现，根因仍未定位；不能据此称风险已消除。
- 本版为预发布，不把构建、合成回归或前序真机复用扩大为所有硬件场景通过。

其余功能、故障处理与使用限制见[支持说明](SUPPORT.md)。旧中继附件保留在[历史版本](PUBLIC_RELEASE.md)，不用于直连设备的配对或转写。
