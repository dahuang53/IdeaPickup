后端 `linux/arm64` 和 `linux/amd64` 已实际构建并完成空卷初始化、配置、配对、WAV／Opus、重启／重建、HTTPS 根／子路径、错误证书、权限、清理和故障测试。arm64 是 Docker Desktop Linux VM 原生运行，amd64 是模拟运行；Linux UID／Unix peer／秘密文件权限结论限定实际 VM 内核和命名卷，没有独立原生 x86 宿主性能资格。

兼容源码镜像更新实测保留配置、实例、设备授权和成功状态，不恢复旧数据库。真实千问→思源完成一次合成语音投递并由所有者确认；暂存音频、正文和配置引用已清理。到期故障用明确的偏移时钟模拟 24 小时，空间故障用有界临时文件系统，不声称实际等候 24 小时、宿主满盘或当前持续一小时负载通过。
